# Dungeon Slashers

# Integrantes:
- Lautaro Lizardi 
- Felipe Gonzalez

# Descripcion:
Un simple RPG por turnos donde 4 heroes descenderán a una mazmorra para completar su último encargo.

# Tecnologias utilizadas:
- LibGDX
- Computadoras con Sistema Windows, Linux y Mac
- Gradle
- EclipseIDE

# Instrucciones:
1. Ir a releases/lastest
2. Descargar el .zip de la ultima versión para el sistema que esta usando
3. Ejecutar el juego
4. disfrutar
