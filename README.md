# Dungeon Slashers

# Integrantes:
- Lautaro Lizardi 
- Felipe Gonzalez

# Descripcion:
Un simple RPG por turnos donde 4 heroes descenderán a una mazmorra para completar su último encargo.

# Tecnologias utilizadas:
- LibGDX
- Computadoras con Sistema Windows
- Gradle
- EclipseIDE

# Instrucciones:
1. Clonar el repo
2. Tener un método para ejecutar .JAR
3. Ejecutar el .JAR
